# Heap — построение бинарной кучи в VS Code

## Описание проекта

**Heap** — расширение для VS Code, которое строит бинарную кучу по данному массиву в на языке C++.
Расширение работает с помощью маркеров.

## Возможности

- Построение максимальной кучи (Max Heap).
- Построение минимальной кучи (Min Heap).
- Поддержка типов `short`, `int`, `long`, `long long`, `unsigned int`.
- Работа с большими целыми числами с помощью `BigInt`.
- Проверка корректности элементов массива.
- Проверка соответствия указанного размера массива количеству элементов.
- Проверка диапазонов поддерживаемых типов.

## Использование

Необходимо объявить массив в C++ и добавить соответствующий маркер.

### Максимальная куча

```cpp
int arr[] = {10, 20, 5, 30, 15};
arr.heapmax
```

### Минимальная куча

```cpp
int arr[] = {10, 20, 5, 30, 15};
arr.heapmin
```

После обработки маркеры удаляются, а массив заменяется результатом построения кучи.

## Используемые технологии

- TypeScript
- Visual Studio Code Extension API
- Node.js
- npm

## Алгоритм

Для построения бинарной кучи используется алгоритм `Build Heap`, основанный на многократном применении операции `Heapify`, что гарантирует пострение за O(n).

Сначала определяется последний родительский узел, после чего выполняется восстановление инварианта кучи для каждого родительского узла в обратном порядке.
